# Block World multiplayer server — Classic Expansion

Node.js server for Block World.

Render settings:
- Build: `npm install`
- Start: `npm start`
- Health check: `/health`

Required files in GitHub:
- `server.js`
- `game-rules.js`
- `package.json`
- `render.yaml`

The client is configured for:
`https://block-world-server-dsh2.onrender.com`
