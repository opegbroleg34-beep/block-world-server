# Block World multiplayer server

Готовый HTTP-сервер под текущий клиент Block World.

## Что поддерживает

- `POST /api/join` — создать комнату или войти по 12-значному коду.
- `POST /api/sync` — позиции, поворот камеры, предмет в руке, приседание и состояние мира.
- `POST /api/action` — добыча/установка блоков, двери, крафт, сундуки, выбрасывание/подбор предметов, здоровье и голод.
- `POST /api/leave` — выход игрока.
- `GET /health` — проверка работы сервера.

Коды комнат выглядят так: `7F99A8643009`.

## Как выложить на Render

1. Создай новый репозиторий GitHub, например `block-world-server`.
2. Загрузи в корень репозитория все файлы из этого архива.
3. На Render выбери **New → Web Service** и подключи этот GitHub-репозиторий.
4. Runtime: **Node**.
5. Build Command: `npm install`.
6. Start Command: `npm start`.
7. Health Check Path: `/health`.
8. Для первого теста можно выбрать Free.
9. После Deploy скопируй адрес вида `https://block-world-server-xxxx.onrender.com`.
10. Открой `CLIENT-PATCH.txt` и вставь этот адрес в игру.

## Проверка

Открой в браузере:

`https://ТВОЙ-СЕРВЕР.onrender.com/health`

Должен появиться JSON с `"ok": true`.

## Сохранение

Сервер пишет комнаты в `world-data.json`. На **Free Web Service** Render файловая система временная: при spin-down, рестарте или redeploy локальные изменения могут быть потеряны. Поэтому эта версия подходит для проверки онлайна и комнат. Для постоянных миров следующим шагом подключим базу данных.

## Важно про Free

Free Web Service может засыпать после периода без входящего трафика. Первый запрос после сна будет ждать запуска сервера. Для теста это нормально.
